# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A single-file web page (`index.html`) that draws a Tagima Sixmart guitar in SVG, lets the user pan/zoom to any part, and shows specs and setup values per part. No build step, no dependencies, no server. Everything (CSS, SVG construction, data, interaction) lives in `index.html`.

## Commands

```bash
open index.html                      # run it

# Render a view headlessly to check a visual change (the only "test" there is)
C="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$C" --headless=new --disable-gpu --window-size=1400,1000 --virtual-time-budget=3000 \
  --screenshot=/path/out.png "file://$PWD/index.html#bridge"   # any part key works as the hash

# Catch a JS error (headless Chrome does not print console errors): inject onerror, read the title
sed 's#<head>#<head><script>window.onerror=(m,s,l,c)=>{document.title="ERR "+m+" @"+l+":"+c}</script>#' index.html > /tmp/t.html
"$C" --headless=new --disable-gpu --virtual-time-budget=3000 --dump-dom file:///tmp/t.html | grep -o '<title>[^<]*</title>'
```

Verify every drawing change with a screenshot; a change that renders nothing usually means a JS error that stopped the script partway (the panel comes up empty).

## How the drawing is built

The SVG is generated by JavaScript at load time, not written as markup. Read these in order in `index.html`:

- **Coordinate system (`geometry` section).** One unit = 648/820 mm. The nut is at `y = NUT = 250`, the neck centerline at `x = CX = 300`, the scale length is `SCALE = 820` units (25.5" = 648 mm). Fret positions come from `fretY(n)` (12th-root-of-2 rule); string x positions from `nutX`/`sadX`/`strX`. Every hard-coded coordinate in the file is in this system, so a part can be placed from a millimetre measurement: `units = mm * 820/648`.
- **Outlines `BODY`, `GUARD`, `HEAD`** are long path strings traced automatically from flat product photos (silhouette against the white background, smoothed, converted to Catmull-Rom curves, scaled by the fret spacing of the photo). Do not hand-edit them; re-trace if the shape must change. Measured sizes: body 319 × 466 mm, pickguard 218 × 273 mm, headstock 90 × 185 mm from the nut.
- **Parts** are created with `part(key)`, which makes a `<g class="part" data-part="key">`. Draw order is z-order. The control plate is clipped to the pickguard (`#guardClip`), the headstock grain to the headstock (`#headClip`).
- **Control positions** are the constants `VOL, TONE, DR, TOG, LED, SEL, RJ, PJ`, declared *before* the control-plate block because the plate polygon is derived from them. Labels and the plate are relative to these constants; move a knob by changing its constant only.
- **`PARTS` object** is the content: one entry per `data-part` key with `name`, `group`, `what`, `specs`, `setup`, optional `tuning` and `ctl`. Every spec row carries a source tag: `spec` (retailer listing), `photo` (seen/measured on the owner's photos), `ref` (generic Strat setup value), `inferred` (worked out, unconfirmed). Keep tags honest; the legend in the panel footer explains them to the reader. A part with no `PARTS` entry crashes hover/select.
- **Electronics state `ST`** (volume, push-pull, mode, tone, delay, reverb, selector) is persisted in `localStorage` and drives both the panel controls and the knob rotations in the SVG via `applyState()`.
- **Preset API** (`presets API` section at the end of the script). `applyConfig(cfg)` normalizes a config (`SCHEMA` keys: pickup, effects, mode, volume, tone, delay, reverb, title, note), sets `ST`, draws numbered callouts into `#presetLayer` (outside `#world`, so "fit" ignores it) and renders the step list in the overview. Entry points: `index.html#key=value&…` (or `?query`), `window.sixmart` (`apply`, `get`, `steps`, `link`, `clear`), and `postMessage({type:'sixmart:apply',config})`. `#api` opens the in-page reference. `API.md` is the same reference for agents reading the repo: change both together.
- **Pan/zoom** works by animating the SVG `viewBox` (`setVB`, `animateTo`, `boxView`). Selecting a part zooms to its `getBBox()` and sets `location.hash` to the key, so `index.html#<key>` deep-links to a part. Clicks use `elementFromPoint` on pointer-up, so pointer capture during drags does not break part selection.
